Unidades Académicas

Estructura curricular de 16 semanas organizadas en 4 unidades. Haz clic en cada semana para revisar el temario y avances.

UNIDAD 01 Kawasaki Ninja

Fundamentos y Estructura

Arquitectura inicial, maquetación estándar y semántica del proyecto.

Semana 1: Introducción & Configuración
  • Configuración del entorno de desarrollo (VS Code, Git).
  • Estructura básica e historia del lenguaje.
  • Creación del primer repositorio de trabajo.
Semana 2: Estructura HTML5 & Semántica
  • Etiquetas semánticas (`header`, `nav`, `main`, `section`).
  • Formularios y validaciones nativas.
  • Buenas prácticas de accesibilidad web (A11y).
Semana 3: Estilos Fundamentales CSS3
  • Modelo de caja (Box Model) y posicionamiento.
  • Selectores avanzados y especificidad.
  • Variables CSS y arquitectura de código limpio.
Semana 4: Diseños Flexibles (Flexbox)
  • Alineación de componentes con Flexbox.
  • Creación de estructuras responsivas.
  • Entrega del primer hito del proyecto.
UNIDAD 02 Honda CBR

Lógica e Interacción

Control de flujo, eventos e interacción con el usuario mediante JavaScript.

Semana 5: Fundamentos de JavaScript
  • Tipos de datos, variables y operadores.
  • Estructuras de control condicionales y bucles.
  • Funciones puras y scope de variables.
Semana 6: Manipulación del DOM
  • Selección y modificación dinámica de elementos HTML.
  • Manejo de eventos (Click, Keydown, Submit).
  • Creación interactiva de elementos dinámicos.
Semana 7: Asincronía y Fetch API
  • Promesas y síntaxis `async / await`.
  • Consumo de datos desde APIs REST públicas.
  • Manejo estructurado de errores (`try/catch`).
Semana 8: Almacenamiento Local & Estado
  • Persistencia de datos con `localStorage` y `sessionStorage`.
  • Manejo básico del estado de la aplicación.
  • Evaluación parcial y presentación de la app.
UNIDAD 03 Ducati Panigale

Diseño Avanzado y Frameworks

Construcción de interfaces complejas y experiencia de usuario (UX/UI).

Semana 9: CSS Grid Layout
  • Maquetación bidimensional con CSS Grid.
  • Grid dinámico y plantillas responsivas.
  • Comparativa y combinación Flexbox vs Grid.
Semana 10: Animaciones & Microinteracciones
  • Transiciones avanzadas y Keyframes en CSS.
  • Optimización de rendimiento gráfico (GPU Acceleration).
  • Efectos interactivos de entrada y salida.
Semana 11: Frameworks Componentizados
  • Introducción a librerías avanzadas de desarrollo.
  • Diseño modular mediante componentes reutilizables.
  • Manejo de propiedades y flujos de información.
Semana 12: Arquitectura UI & Optimización
  • Patrones de diseño de interfaces.
  • Auditoría de rendimiento de carga (Lighthouse).
  • Entrega del prototipo funcional.
UNIDAD 04 BMW S1000RR

Backend, Datos y Despliegue

Conexión con servicios, servidores y la puesta en producción del proyecto.

Semana 13: Fundamentos de Backend
  • Entornos de ejecución de servidor (Node.js).
  • Creación de un servidor web y manejo de rutas.
  • Servicios web y protocolos de comunicación HTTP.
Semana 14: Bases de Datos & Modelado
  • Introducción a bases de datos relacionales y no relacionales.
  • Diseño de esquemas y consultas de datos básicas.
  • Conexión e integración del backend con la base de datos.
Semana 15: Pruebas y Seguridad
  • Pruebas unitarias de código (Testing básico).
  • Autenticación de usuarios y protección de variables.
  • Control de versiones para producción.
Semana 16: Despliegue Final & Presentación
  • Publicación del proyecto en servidores Cloud.
  • Configuración de dominios y certificados SSL.
  • Sustentación final del Portafolio completo.
